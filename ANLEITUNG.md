# SchwesterTV – eigene Startseite für den Fernseher

Das ist der komplett fertige Code für deine eigene Fernseher-Oberfläche.
Du musst daran nichts programmieren.

## Fertige APK herunterladen

1. Oben im Repository auf den Reiter **Actions** klicken.
2. Dort siehst du einen Durchlauf namens "APK bauen". Warte, bis ein
   grüner Haken ✅ erscheint (dauert ein paar Minuten).
3. Klicke auf den fertigen Durchlauf, scrolle runter zu **Artifacts** und
   lade **SchwesterTV-apk** herunter. Entpacke die ZIP-Datei – darin
   liegt `app-debug.apk`.

## Die App auf den Fernseher bringen

1. Kopiere `app-debug.apk` auf einen leeren USB-Stick.
2. Stick in den Fernseher stecken.
3. Auf dem Fernseher den Dateimanager öffnen, zum USB-Stick navigieren,
   die `.apk`-Datei antippen.
4. Falls "Installation aus unbekannten Quellen blockiert" kommt: einmal
   in den Einstellungen erlauben (normaler Schalter, keine Gefahr) –
   dann nochmal antippen.
5. Fertig installiert! In den Fernseher-Einstellungen kannst du sie als
   Standard-Startbildschirm festlegen.
